# RTL Practice

用于实习面试中的 RTL（寄存器传输级）手撕训练。

## 目录约定

每个练习独立放在 `exercises/` 下的单独目录中，并遵守以下约定：

- `README.md`：该练习的唯一规格说明，包含功能、时序、边界条件、验收要求，以及冻结的最小 SystemVerilog（系统级硬件描述与验证语言）端口。
- `golden/`：预留给 Codex 编写参考实现和参考测试平台。参考答案必须严格遵守上级 `README.md`，不得私自修改模块端口或行为约定。
- 后续个人练习代码应与 `golden/` 分离，避免在首次手撕前直接看到参考答案。

## 通用规则

1. 除非单题另有说明，时序逻辑均在时钟上升沿更新。
2. 名为 `rst_n` 的复位均为低有效；具体是异步还是同步，以单题规格为准。
3. 参考实现必须可综合，不依赖厂商专有 IP。
4. 不允许为了让测试通过而增加规格中未定义的端口。
5. `golden/` 中的参考实现应优先保证行为清晰、边界条件完整和面试可解释性，而不是堆叠不必要的技巧。

## 当前练习

共 18 个练习，覆盖基础 RTL、握手与 FIFO（先进先出队列）、仲裁、存储器、CDC（跨时钟域）、流水线以及 NPU（神经网络处理器）数据通路。
