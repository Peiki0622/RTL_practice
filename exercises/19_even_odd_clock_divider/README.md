# 19 奇偶分频器 — 规格说明

## 目标
实现一个可综合的奇偶分频器，同时练习偶数分频的单边沿计数结构，以及奇数分频为获得严格 50% 占空比所需的双边沿相位拼接结构。

## 冻结端口
```systemverilog
module even_odd_clock_divider #(
    parameter int unsigned EVEN_DIV = 6,
    parameter int unsigned ODD_DIV  = 5
) (
    input  logic clk,
    input  logic rst_n,
    output logic clk_div_even,
    output logic clk_div_odd
);
```

## 参数约束
- `EVEN_DIV` 必须为不小于 2 的偶数。
- `ODD_DIV` 必须为不小于 3 的奇数。
- 测试不会使用非法参数。
- 两个分频系数均为编译展开阶段固定参数，不要求运行时动态修改。

## 功能要求
- `rst_n` 为低有效异步复位。复位有效时，`clk_div_even` 与 `clk_div_odd` 都必须立即为 0。
- 释放复位后，两个输出只能依据输入 `clk` 的边沿变化，不得通过延时语句制造波形。
- 偶数分频输出 `clk_div_even`：
  - 完整输出周期必须等于 `EVEN_DIV` 个输入时钟周期。
  - 高电平和低电平持续时间必须相等，因此占空比严格为 50%。
  - 只需使用输入时钟上升沿实现。
  - 复位释放后，从低电平开始；经过 `EVEN_DIV/2` 个输入时钟上升沿后第一次翻转为高电平。
- 奇数分频输出 `clk_div_odd`：
  - 完整输出周期必须等于 `ODD_DIV` 个输入时钟周期。
  - 高电平和低电平持续时间必须相等，因此占空比严格为 50%。
  - 为得到半个输入时钟周期的时间分辨率，允许并要求使用输入时钟上升沿与下降沿分别产生相位，再组合为最终输出。
  - 复位释放后的第一个输入时钟上升沿，`clk_div_odd` 第一次拉高。
- 不得把任一分频输出作为本模块内部其他时序逻辑的时钟；所有状态都必须直接由输入 `clk` 的上升沿或下降沿驱动。
- 不得使用自定义 `function`（函数），并遵守仓库根目录 `AGENTS.md` 的其余编码约束。

## 边界条件
- 必须正确处理最小合法偶数分频 `EVEN_DIV=2`。
- 必须正确处理最小合法奇数分频 `ODD_DIV=3`。
- 异步复位可以在任意时刻拉低，两个输出都必须立即回到 0。
- 释放复位后允许重新开始新的确定性分频相位，不要求保持复位前相位。

## 验收重点
复位、偶数分频周期、偶数分频 50% 占空比、奇数分频周期、奇数分频 50% 占空比、奇数分频双边沿结构，以及复位后的确定性启动相位。
