# 03 1011 序列检测器 — 规格说明

## 目标
设计一个允许重叠匹配的串行比特序列检测器，目标序列固定为 `1011`。

## 冻结端口
```systemverilog
module sequence_detector (
    input  logic clk,
    input  logic rst_n,
    input  logic bit_in,
    output logic match
);
```

## 功能要求
- `rst_n` 为低有效异步复位，复位后无任何已匹配前缀，`match=0`。
- 每个 `clk` 上升沿都认为 `bit_in` 有效，不额外提供有效信号。
- 当本次采样使最近 4 个有效输入构成 `1011` 时，`match` 在该次采样后拉高 1 个时钟周期。
- 必须允许重叠匹配。例如输入流 `1011011` 应检测到两次匹配。
- `match` 不得保持多拍。

## 实现限制
- 可使用 Moore 型或 Mealy 型有限状态机，但外部可见时序必须符合本规格。
- 不允许通过移位保存无限历史；实现应体现有限状态机或等价的有限历史逻辑。

## 验收重点
普通匹配、无匹配、重叠匹配、连续多个候选前缀。
