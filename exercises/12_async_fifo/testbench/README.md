# Testbench 目录

此目录用于存放该练习的 SystemVerilog（系统级硬件描述与验证语言）测试平台，由 Codex 后续编写和维护。

要求：

- 同一套测试平台必须能够分别验证 `golden/` 中的参考实现和 `practice/` 中的练习实现。
- 测试平台必须严格依据上级 `README.md` 中冻结的模块端口、时序和边界条件，不得为测试方便修改被测设计接口。
- 默认编译时只选择一个被测实现：要么 `golden/`，要么 `practice/`，避免同名模块重复定义。
- 测试平台应尽量采用自检方式，能够明确报告通过或失败，并覆盖规格中列出的关键边界场景。
- 测试平台同样受仓库根目录 `AGENTS.md` 约束，尤其禁止定义或使用自定义 `function`。
- 本目录只存放验证相关文件，不存放被测 RTL（寄存器传输级）实现。
